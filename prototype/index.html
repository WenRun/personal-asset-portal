个人资源门户 · UI 原型

方案 A · 纯静态 HTML + Tailwind CDN · 点击卡片进入各界面

对应《详细设计》§7 前端设计；布局骨架 = AppShell（左导航 + 顶搜索 + 主区网格 + 详情侧栏）。所有数据为示意 mock。

01 · §7.2 /images
图片浏览页（AppShell + 瀑布流）
信息密度最高的浏览形态：月分组、筛选 chips、悬停选择/收藏、缩略图直出。
02 · §7.2 /fonts
字体样张墙
验证布局骨架对差异形态的适应：全局预览文案、字重/语言筛选、字族卡片。
03 · §7.4 FontSpecimen
字体详情侧栏
样张预览、可变字体轴滑杆、字符集区块覆盖率、字族打包下载。
04 · §7.4 VideoPlayer
视频详情页（教程系列）
播放器占位、续播提示、系列集数列表与进度、整季打包下载。
05 · §7.4 CommandPalette
Cmd+K 全局搜索弹层
五类聚合结果、类型分组与计数、键盘导航。
06 · §6.1 /login /register
登录 / 注册
开放注册口径、bootstrap admin 说明。
07 · §4.7 访客态
访客浏览态
搜索置灰、详情点击弹注册引导——验证「可浏览、不可搜/预览」的权限口径。
08 · §6.5 管理端
任务中心 / 入库确认队列
jobs 表可视化、失败重试、视频系列识别人工校对。
09 · §7.2 /music
音乐浏览页（专辑墙）
专辑/艺术家/曲目三种视图切换、悬停播放、格式筛选、全局底部播放条（跨页不中断）。
10 · §7.2 /books
书籍浏览页（书封墙）
系列分组、阅读进度徽标、格式标记（MOBI/AZW3 仅下载）、网格/列表切换。
11 · §7.2 /videos
视频浏览页（视频墙）
教程系列卡片（集数/进度/已看完徽标）+ 素材片段区，两级结构对应 Series↔Video 模型。
12 · §7.4 Lightbox
图片详情（Lightbox + EXIF）
暗色查看器、左右切换、胶片条、EXIF 信息面板、派生物清单。
13 · §5.2 专辑详情
专辑详情（曲目列表）
专辑头 + 曲目表（正在播放态、LRC 歌词标记、码率）、播放全部/整包下载、播放条联动。
14 · §5.4 书籍详情
书籍详情 + 阅读器弹层
多格式文件盒（EPUB/PDF/MOBI）、阅读进度与继续阅读、点「继续阅读」弹出阅读器示意。
原型说明：Tailwind 通过 CDN 加载需联网；缩略图/封面均为渐变占位块；未经确认的视觉决策（主色、密度、圆角）以本原型为准，转入 M0 后迁移为 shadcn/ui 组件。
