## 一句话产品说明

自建个人门户，统一管理 **字体、音乐、视频、书籍、图片** 五类本地文件：目录扫描或网页上传入库，不搬移不改名；支持检索、在线预览、下载、分享。多用户共用同一资源库，收藏按人隔离。生产跑在飞牛 NAS（`http://192.168.31.31:8080`）。
