# 近期功能变更（M6 交接之后）

> 范围：`4dbe006`（2026-10-07 HANDOFF）之后到 `a1470d6`（2026-10-20）。  
> 更早的 M0–M6（五类入库、搜索、打包、分享、智能集合）见仓库根目录 [HANDOFF-asset-portal.md](../HANDOFF-asset-portal.md)。  
> 实现细节以 [技术指南](./technical-guide.md) 为准。

交接当天已经把「标签进搜索、字族打包、详情页分享、浏览页批量入包、标签树、任务 SSE、LRC 歌词、Alembic、NGINX 接线、扫描对账」补进主线。下面按主题写 **10-08 起真正新长出来的能力**，并带上交接当天那批补完项里后续又改过的部分。

## 1. 电子阅读器

**效果：** EPUB / PDF / MOBI / AZW3 / TXT 都能在网页里读，进度跟账号走。

- TXT 按编码探测（UTF-8 / GB18030 / Big5 等）分章，合成一本给阅读器用的 `reader.epub`，并用 Pillow 画一张封面。
- MOBI / AZW3 解包后归一成同一份 `derived/books/{id}/reader.epub`（插图打进包、按 pagebreak / 章回标题拆章）。
- 流式排版：仿真分页 和 长卷滚动 两种模式；字号、行距、版心、无衬线 / 宋体 / 楷体；日间 / 羊皮纸 / 豆沙绿 / 暗黑四套主题；章节大纲抽屉；`F` 全屏；左右热区、键盘、滚轮翻页。
- PDF 不走浏览器自带阅读器：后端 PyMuPDF 按页出图（JPEG，失败回退 PNG），前端 `PdfReaderCore` 翻页。缩放 50%–250%（顶栏胶囊、Ctrl/⌘+滚轮、双指捏合、`+`/`-`/`0`、双击、放大后拖拽）。主题用 CSS 滤镜套到页面图上。翻页热区拉满屏幕左右两侧。
- 书架「在读 / 未读」筛选和角标改回读批量进度接口，不再是空数据。

## 2. 视频播放与教程系列

**效果：** 详情页是 B 站风格播放器；课程文件夹会收成「一个系列 + 按章列出集数」。

- 播放器：系统全屏 / 网页全屏 / 画中画、倍速（点击固定菜单，消除悬停盲区）、进度条悬停预览、控制栏自动隐藏。快捷键：空格暂停、`F` 全屏、`W` 网页全屏、`P` 画中画、`M` 静音、方向键与 `J`/`L`/`K`。
- 观看进度写到云端；列表卡片显示已看进度；教程切集走 SPA（不整页白屏），切走前保存进度，播完自动下一集。
- 目录形如 `课程名/第N章 xxx/01.mp4`：系列名取课程（祖父目录），章号写入 `video_details.chapter`，集数是章内序号。文件名 `章号-集号` 不再把章号误当成集号。
- 入库确认队列按「同系列同章」顺序给建议集号（已确认最大集号 + 1，再按文件名自然排序递增），不再一律填 1。
- 视频容器从 7 种扩到 20 种（补 `.m4v` `.ts` 以及 `.f4v/.flv/.rm/.rmvb/.wmv/.mpg/.mpeg/.m2ts/.mts/.3gp/.3g2/.vob/.asf`）。`mkv` / `webm` 只要编码在 Direct Play 白名单内就能在线播（修复了 ffprobe 报 `matroska,webm` 时只看第一段、WebM 永远判失败的问题）。MPEG-2 / FLV / RealMedia 等仍只能下载。
- 详情页可编辑标题 / 备注 / 标签 / 评分，五星悬停高亮后点击保存。

## 3. CUE 分轨与发烧友音频

**效果：** APE / DSD / AIFF / Opus / WMA / ALAC / DTS 能入库并在浏览器里听；一张 CUE + 母带会变成带「CUE」徽标的分轨专辑。

- 非浏览器原生格式、以及 5.1 / 7.1 / 4.0 等多声道，后台转成 320 kbps 立体声 `stream.mp3` 给 `<audio>` 播；下载仍是原文件。
- CUE：多编码探测（UTF-8 / GB18030 / Big5 / Shift-JIS 等），INDEX 按 75 帧/秒换算时间；母带按精确名 → 换扩展名 → 同 stem → 模糊包含 → 目录最大音频依次找。分轨是虚拟资产（`storage_key` 形如 `cue:{cue资产id}/track_NN.mp3`），切片落在 `derived/music/`。
- 播放失败不会把整张专辑循环到卡死；母带或 CUE 表被对账软删后，分轨子资产按 `meta.cue_asset_id` 一并软删，列表里不再留幽灵曲目。
- 曲目标题去掉 `01.` / `02 - ` 这类音轨号；`歌名 - 歌手` / `歌手 - 歌名` 会拆开，未知歌手时用启发式提取。
- 设置里单文件上传上限可调 1–128 GB。

## 4. 图片格式（36 种）

**效果：** 相机 RAW、HEIC、SVG、PSD、AI 都能进图片库；墙上一律用 WebP 缩略图（SVG 不栅格化，端点回退原文件并加 CSP）。

- 常规：jpg / jpeg / jfif / png / webp / gif / bmp / tif / tiff
- 新容器：heic / heif / avif（依赖 `pillow-heif` / `pillow-avif-plugin`；缺库仍入库，带 `parse_warning`）
- 设计稿：svg / ico / psd / ai（AI 用 PyMuPDF 渲首页）
- RAW 20 种：crw / cr2 / cr3 / nef / nrw / arw / srf / sr2 / raf / orf / rw2 / rwl / pef / srw / x3f / 3fr / erf / iiq / mrw / dng。缩略图优先内嵌 JPEG，否则 LibRaw。浏览器不能直接显示 RAW，Lightbox 失败时色块占位，下载仍可用。
- 详情页可编辑元数据、打分、下原图。

## 5. 三合一分类 + Eagle 风格侧栏

**效果：** 每个浏览页左边是文件夹树（全部 / 待归类 / 多级路径），和磁盘目录、手动整理、系统推荐对得上。

- **目录继承：** 扫描时把 `storage_key` 里文件名之前的相对路径写成 `assets.category`（如 `计算机/Python`）。历史迁移只回填了第一级，新扫描才是多级。
- **手动：** 编辑弹窗里的分类树选择器（Eagle / Finder 风格）；浏览页多选后批量改分类 / 采纳推荐 / 清空。
- **推荐：** 解析器按元数据猜 `suggested_category`（有相机信息 → 摄影相片，教程视频 → 教程系列，等），卡片上可一键采纳。只在推荐字段为空时写入，不覆盖用户已选分类。
- 扫描根增加 **类型白名单**（设置页勾选）。音乐目录里的封面 jpg 不会再混进图片库；不在白名单里的存量记录，对账时会软删。

## 6. 收藏按用户隔离

**效果：** 每人一颗心；游客永远看不到实心；「我的收藏」是登录用户自己的聚合墙。

- 去掉 `assets.is_favorite` 全局列，改 `user_favorites (user_id, asset_id)`。存量实心划给最早的管理员（没有管理员就划给最早注册的用户）。
- 五类详情页和图片墙的心形真实 PATCH；失败回滚。专辑「收藏」会对该专辑全部曲目逐条写入（专辑本身不是资产）。
- 按「仅收藏」打包 ZIP 时，只打发起人自己的收藏。

## 7. 用户、资料、游客仪表盘

**效果：** 访客能看仪表盘和五类列表；要进详情 / 搜索会被请去登录或弹出注册引导。管理员有用户管理页。

- 注册页签真正走注册接口（曾经误调登录）；用户名 2–32、密码至少 8 位。
- 点侧栏头像改用户名、密码、选填邮箱 / 手机（可清空）。改密码必须带当前密码。
- 侧栏二级菜单：游客全隐；注册用户只见「我的收藏」和「工具箱」；管理员再加标签 / 任务 / 用户 / 设置。
- 仪表盘公开：五类计数 + 最近入库（带真实封面，失败用色块）。任务摘要仅登录可见。访客点卡片弹注册引导，不直接进详情。
- 用户管理：改角色、停用（立即清会话）、重置密码、删除（级联清会话 / 收藏 / 打包 / 集合 / 进度 / 分享）。不能停用或删除自己，也不能动掉最后一名管理员。

## 8. 扫描对账与删除

**效果：** 磁盘上文件没了，再扫一次，库里对应记录进回收站（可恢复），搜索索引和缩略图一起清掉。

- 安全阀：根目录 **缺失或列不出内容**（很像 NAS 盘没挂上）→ 跳过对账，避免把整库软删。目录还在、只是被清空 → 照常软删。判断必须发生在 `build_storage` 之前，因为后者会对缺失路径 `mkdir`，会把「挂载丢失」伪装成「空目录」。
- 五类详情页删除：只删记录（软删，可恢复）或连源文件一起 purge。
- 恢复时重新入队解析，补派生物。

## 9. 任务中心

**效果：** 任务表实时刷新；能删掉已经结束或失败的记录，不影响资源本身。

- SSE（`pg_notify`）替代轮询；顶栏显示已连接 / 重连中。分页以 REST 为准，SSE 只当「去刷新」的信号。
- 类型中文名、对象列带类型徽标和详情链接（音乐跳专辑；已软删不再跳）、耗时列、失败重试倒计时、尝试次数 `x/3`。
- 单条删除、本页批量删除；**运行中的任务不能删**。失败可点重试。

## 10. 详情页资源路径

五类详情展示文件在数据根下的相对路径，并去掉顶层 `library/`。例如磁盘上是 `/data/library/images/a.jpg`，页面显示 `images/a.jpg`。不在数据根内的路径回落为绝对路径。

## 11. 部署与发布

- 生产入口定为 **NGINX**（不再用 Caddy）：`/api` 反代、上传体积对齐、SSE 关缓冲、音视频 Range 透传、SPA 回退。
- server 镜像带 Alembic 目录和 ffmpeg（视频封面帧、音频转码、CUE 切片都靠它）。
- 数据目录改为 bind mount `./data:/data`，NAS 上可用 SMB 直接往 `library/<分类>/` 拷文件再扫描。
- 真实 NAS 发布脚本（含主机、口令）移出仓库，只留脱敏的 `deploy/release-to-nas.sh.example`。

## 12. 其它体验

- 侧栏点击、路由切换、后台任务完成后自动拉最新列表，不用整页刷新。
- 全局搜索弹窗：ESC、失焦后按键、回车兜底、上下键循环并滚动跟随。
- 路由级 `lazy()` + vendor 拆块，入口体积从约 380KB 降到约 37KB。
- 小屏：详情侧栏改抽屉，表格可横向滚，375px 走查过一轮。

## 13. 图书元数据刮削（Google Books，第一期）

**效果：** 入库时只有文件名、作者出版社简介一片空白的书（尤其 PDF / TXT），会自动联网补齐；搜出多个候选的进确认队列人工点一下。

- 查询两级：ISBN 直查（PDF 解析新增扫前 8 页版权页文本抽 ISBN，校验位把关）→ 书名 + 第一作者兜底。
- 只填空缺字段，用户手填的绝不覆盖；网络评分存 `meta`，不动「我的评分」；简介写入备注。
- 封面：仅无封面或合成占位封面（TXT / 无封面 MOBI）时下载替换，落 `cover_src` 后复用既有封面派生；重扫不再把下载的真实封面冲掉。
- 多候选 → 管理端确认队列新增图书卡片（候选带封面缩略图 / 作者 / 出版社 / ISBN / 评分，可跳过）；顶部「批量刮削缺失图书」一键补全。
- 任务中心新增「刮削图书信息」类型，失败自动退避重试。
- 配置全套走 `.env`：总开关 / 超时 / 出站代理 / Google Books API key（免 key 匿名配额常被用光报 429，建议申请免费 key）。

## 14. 图书元数据刮削第二期（豆瓣）

**效果：** 中文书自动补豆瓣评分（详情页「我的评分」旁绿色徽标）、丛书、中文简介、封面大图；豆瓣查不到再走 Google。

- 豆瓣无官方 API，走网页端点（全部免登录）：ISBN 直查（`/isbn/` 跳转即权威命中）、`subject_suggest` 书名搜索、详情页解析（#info 兼容分行排版、JSON-LD、og:image、`v:average` 评分、内容简介）。
- 豆瓣国内直连不走代理（代理是海外出口，访问豆瓣反而易触发风控）；进程内限速约 1 次/秒，被风控时任务退避重试并记录 `douban_error`，不拦 Google 兜底。
- suggest 对长查询敏感：书名+作者组合常 0 结果，只用纯书名搜索；同名多版本（如《置身事内》2021/2023 版）进确认队列人工选，应用时自动取详情页补全。
- providers_tried 补量机制：上线后点一次「批量刮削」，存量书（含第一期 Google 已成功的）自动补豆瓣评分/丛书/封面，每本只补一次、不重复消耗 Google 配额。
- 封面下载按域名分流：doubanio.com 直连，Google/OpenLibrary 走代理；确认队列候选带豆瓣/Google 徽标与丛书、豆瓣 0-10 分展示。
- 配置 `SCRAPE_DOUBAN_ENABLED`（默认开，想只用 Google 改 false）。

## 15. AI 元数据识别（一期：图片 / 视频 / 书籍 / 字体）

**效果：** 在四类资源详情页点「AI 识别」，大模型看现成的缩略图 / 抽帧 / 封面 / 样张 + 文件信息，自动补简介、更新推荐分类，并给出标签 / 标题等建议（带一键采纳）；音乐二期按专辑单独做。

- **配置全在设置页**（不进 .env）：接口地址 / API Key / 模型名 / 代理 / 超时，保存即生效（worker 每次任务实时读库，无需重启容器）。协议为 OpenAI 兼容——智谱 `glm-4.5v`、通义 `qwen-vl-max`、OpenAI、局域网 Ollama 同一套配置；模型必须支持看图。
- **测试连通性按钮**：发一张纯色小图做最小视觉调用，同时验证地址可达、Key 有效、模型存在且真的能看图（回复会显示模型看到的颜色）；失败原因翻成大白话（401=Key 错、404=地址/模型名错、超时=网络/代理……）。
- **安全口径与图书刮削对齐**：`note` 只填空缺绝不覆盖；`assets.rating` 永不写；标签 / 标题 / 视频系列名 / 书籍出版信息只存 `meta.ai_enrich.suggestions`，详情页展示并由管理员一键采纳（标签采纳走增量创建挂载，幂等）；AI 不采信书号（ISBN 只信豆瓣 / Google / PDF 扫描）。
- 证据收集零新增派生：图片用 thumb_1024（压到长边 768 再发）、视频用 10% / 60% 两张抽帧、书籍用真实封面（cover_src 优先）、字体用样张 PNG；prompt 附带该类型现有分类树，让 AI 优先沿用你的分类体系。
- 触发入口：详情页单资源（手动点击即重跑，完成后自动轮询刷新结果卡片）；任务中心顶部「AI 批量识别」按类型批量入队——只挑缺简介且从未识别过的，书籍仅限在线刮削已到头（未收录 / 多候选 / 人工跳过）的，每类单次上限 500 条防误触烧 token。
- 状态与幂等记 `meta.ai_enrich`（ok / not_found / error / skipped + model / tokens / 时间）；识别失败原因原文落 meta 便于排查；配置中途被关掉的任务落 skipped 不报红。API Key 存 settings 表、读接口只回掩码（前 3 后 4）。
